✅ 2. Acciones del socio conectadas a API real

Todas las acciones del socio ahora pasan exclusivamente por los endpoints del backend:

Iniciar tarea → POST /api/tareas/[id]/transition (→ en_progreso)

Iniciar bloque → POST /api/tareas-subtareas/[id]/iniciar

Subir evidencia → compresión 1200px + upload

Enviar bloque para validar → POST /api/tareas-subtareas/[id]/enviar-validar

Rehacer bloque rechazado → iniciar nuevamente (rechazado → en_progreso)

Resultado:
No hay cambios locales de estado sin aprobación del backend.
