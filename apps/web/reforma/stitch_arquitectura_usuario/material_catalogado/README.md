# Catalogación de material Stitch

Este bloque agrupa el material original por decisión arquitectónica, sin borrar carpetas fuente.

- `conservar/`: referencia canónica por módulo.
- `fusionar/`: variantes que deben consolidarse en un único flujo.
- `eliminar/`: material descartado por redundancia.
- `revisar/`: material ambiguo o dependiente de definiciones de negocio/UX.
